# Quickstart Guide
Whether you are using the Full Spectrum or Epilog Laser, review this Quickstart Guide for the general procedure to run a project in the laser cutter.

## Before Starting 
Before starting your project on the laser, go through the following sections. 
### Preparing Your Project
- [ ] Design File is the Proper Format
  - Cutting designs must be a vector graphic, such as a scaler vector graphic (\*.svg) or a drawing file (\*.dwg)
  - Cutting designs can be a raster graphic, such as a \*.jpg (Joint Photographic Experts Group) or portable network graphic (\*.png)
- [ ] Design Page is the Correct Size
  - We recommend setting your page size to match the material you will be cutting on. This way you can design with the layout in mind.
- [ ] Design Vectors are Grouped Appropriately
  - Occasionally the laser will struggle to interpret a design file. Often this can be solved by ungrouping everything to simplify the file as much as possible. 
- [ ] Colors are Set Correctly
  - The laser cutters use colors to distinquish between different settings within a particular project.
  - For example, you may wish to cut partway through cardboard to score it and then all the way through to cut out the design. 
- [ ] Remove any Guidelines or Invisible Elements
  - The laser doesn't necessarily understand whether an element is supposed to be a guideline or invisible, so make sure that you remove any extra elements in your design before sending it to the laser.
  - We recommend saving two versions of your design in this case, one with the guides, and a second copy that is intended to send to the laser.

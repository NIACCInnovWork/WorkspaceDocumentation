# Workspace Documentation
Documentation for the NIACC Innovation Workspace, its equipment, policies, and procedures.

## Welcome!
This is the NIACC Innovation Workspace's documentation for the workspace's equipment, policies, and procedures. This is a great reference to get all of the key information about how to access and use the equipment in the NIACC Innovation Workspace. 
However, **this documentation does not consistute your safety training**! Make sure that you check with workspace staff if you need to complete any trainings prior to using the equipment. 

Instead, this resource is where you look up specific details, like what materials are allowed to be used in the laser cutters, how to clear a jammed 3D printer nozzle, or how to add a request to this documentation.

So, what are you waiting for?! Let's jump in and get started!

## How to Use This Document
This is a reference document. 
If you can not find something open an issue. 
If you want to request new documenation open an issue etc.
